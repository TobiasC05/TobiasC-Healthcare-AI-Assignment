# GitHub Submission Steps

1. Sign in to GitHub.
2. Click **New repository**.
3. Repository name: `ai-healthcare-symptom-triage`
4. Make the repository **Public** if your instructor needs to view it.
5. Upload these files:
   - `app.py`
   - `requirements.txt`
   - `README.md`
   - `RESEARCH.md`
6. Add a commit message such as: `Initial AI healthcare symptom triage project`
7. Click **Commit changes**.
8. Open the repository main page.
9. Copy the repository URL from your browser.
10. Submit that GitHub URL for the assignment.

Suggested submission text:

**GitHub Repository:** YOUR_GITHUB_URL

**Project:** AI-Powered Symptom Checker and Triage Tool

This project demonstrates a simple NLP and machine-learning healthcare application using TF-IDF, Logistic Regression, a Streamlit interface, and a small red-flag safety layer. The application is an educational prototype and is not intended for real medical diagnosis.
